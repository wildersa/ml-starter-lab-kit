## 1. Common Misconceptions & Failure Modes

When designing Deep RL systems and autonomous agent architectures, practitioners frequently encounter conceptual pitfalls. Understanding these failure modes prevents costly engineering mistakes.

---

### Misconception 1: "DQN works directly on continuous action spaces."
- **Reality**: Standard DQN requires computing $\max_{a \in \mathcal{A}} Q(s, a; \theta)$ over all possible actions at every decision step. For continuous action spaces (e.g., steering angle $\theta \in [-180^\circ, +180^\circ]$ or joint torque $\tau \in [-10\text{ Nm}, +10\text{ Nm}]$), taking the max over infinitely many continuous values requires solving a non-convex optimization problem at runtime.
- **Correct Approach**: Use policy-gradient or actor-critic methods (e.g., PPO, SAC, DDPG) that directly output continuous distribution parameters.

---

### Misconception 2: "Replay Buffers can be used directly with standard Policy Gradients / PPO."
- **Reality**: Standard policy gradient methods (REINFORCE, PPO) are **on-policy**. They evaluate expectations $\mathbb{E}_{\tau \sim \pi_\theta}[\dots]$ under the *current* policy $\pi_\theta$. Replay buffers store transitions generated by *older* historical policies $\pi_{\theta_{\text{old}}}$. Applying on-policy policy gradient updates to historical replay samples introduces severe off-policy sampling distribution shift, leading to divergence.
- **Correct Approach**: Use off-policy algorithms (DQN, SAC) when using a Replay Buffer, or use PPO's clipped surrogate objective only across short multi-epoch updates on freshly collected trajectories before clearing the buffer.

---

### Misconception 3: "A single end-to-end Deep RL network should control the entire autonomous agent."
- **Reality**: Forcing a neural network to handle high-level mission goal arbitration, safety constraint enforcement, PDDL symbolic planning, and continuous motor control simultaneously results in brittle black-box failure modes, zero formal safety guarantees, and uninterpretable behavior.
- **Correct Approach**: Enforce **separation of responsibilities**. Use symbolic planners for long-horizon task logic, Behavior Trees for deterministic safety verification and state flow, and Deep RL for high-frequency low-level option execution.

---

### Misconception 4: "Observations ($o_t$) in partially observable tasks can be treated as full MDP states ($s_t$)."
- **Reality**: A single 2D camera image or LiDAR scan lacks velocity information, hidden internal variable states, and historical context. Feeding single observations into standard MDP Q-learning violates the Markov property ($P(s_{t+1} \vert s_t, a_t)$), causing the agent to perceive identical observations as requiring contradictory actions.
- **Correct Approach**: Maintain a recurrent history state vector $h_t = \text{RNN}(h_{t-1}, [o_t, a_{t-1}])$ or stack consecutive frames to approximate a belief state $b_t$.

## 2. Framework-Free Python Checkpoints & Minimal Code

### Checkpoint A: Replay Buffer & Priority Logic in Pure Python

```python
import random
from typing import List, Tuple, Any

class PurePythonReplayBuffer:
    """Minimal, framework-free Replay Buffer managing i.i.d. transition sampling."""

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.buffer: List[Tuple[Any, Any, float, Any, bool]] = []
        self.position = 0

    def push(self, state: Any, action: Any, reward: float, next_state: Any, done: bool) -> None:
        """Store transition tuple (s, a, r, s', d) in FIFO circular buffer."""
        transition = (state, action, reward, next_state, done)
        if len(self.buffer) < self.capacity:
            self.buffer.append(transition)
        else:
            self.buffer[self.position] = transition
        self.position = (self.position + 1) % self.capacity

    def sample(self, batch_size: int) -> Tuple[List, List, List, List, List]:
        """Uniformly sample minibatch of size batch_size."""
        batch = random.sample(self.buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)
        return list(states), list(actions), list(rewards), list(next_states), list(dones)

    def __len__(self) -> int:
        return len(self.buffer)
```

### Checkpoint B: Double DQN Target Equation in NumPy / Pseudocode

```python
import numpy as np

def compute_double_dqn_targets(
    rewards: np.ndarray,       # Shape: (batch_size,)
    next_states: np.ndarray,  # Shape: (batch_size, state_dim)
    dones: np.ndarray,        # Shape: (batch_size,) - boolean or 0/1
    gamma: float,
    online_q_func,            # Callable: online_q_func(states) -> Q-values (batch_size, num_actions)
    target_q_func             # Callable: target_q_func(states) -> Q-values (batch_size, num_actions)
) -> np.ndarray:
    """Computes Double DQN Temporal Difference targets without maximization bias."""

    # Step 1: Action Selection using ONLINE network parameters θ
    next_q_online = online_q_func(next_states)  # (batch_size, num_actions)
    best_next_actions = np.argmax(next_q_online, axis=1)  # (batch_size,)

    # Step 2: Action Evaluation using TARGET network parameters θ⁻
    next_q_target = target_q_func(next_states)  # (batch_size, num_actions)
    batch_indices = np.arange(len(rewards))
    selected_target_q = next_q_target[batch_indices, best_next_actions]  # (batch_size,)

    # Step 3: Compute TD Target y = r + (1 - done) * γ * Q_target(s', argmax_a Q_online(s', a))
    td_targets = rewards + (1.0 - dones.astype(float)) * gamma * selected_target_q
    return td_targets
```

### Checkpoint C: PPO Clipped Surrogate Objective in NumPy

```python
import numpy as np

def compute_ppo_clipped_loss(
    pi_new_probs: np.ndarray,   # π_θ(a_t | s_t) for actions taken
    pi_old_probs: np.ndarray,   # π_θ_old(a_t | s_t) for actions taken
    advantages: np.ndarray,     # Estimated Advantages A_t
    clip_eps: float = 0.2
) -> float:
    """Computes PPO clipped surrogate objective scalar loss."""

    # Step 1: Compute probability ratio r_t(θ)
    ratios = pi_new_probs / (pi_old_probs + 1e-8)

    # Step 2: Compute unclipped surrogate objective
    surr1 = ratios * advantages

    # Step 3: Compute clipped surrogate objective
    clipped_ratios = np.clip(ratios, 1.0 - clip_eps, 1.0 + clip_eps)
    surr2 = clipped_ratios * advantages

    # Step 4: Take element-wise minimum and average over batch
    ppo_objective = np.minimum(surr1, surr2)

    # We negate because standard optimizers perform gradient DESCENT
    loss = -np.mean(ppo_objective)
    return float(loss)
```

## 3. Suggested Diagnostic Hands-On Experiments

Try these hands-on diagnostic exercises to test your understanding of RL mechanics:

1. **Replay Buffer Ablation Study**:
   - Implement a simple 2D Gridworld environment.
   - Train a minimal neural network Q-approximator with and without a Replay Buffer (i.e., sequential online updates vs. randomized minibatch updates).
   - Plot loss trajectories and observe how online updates oscillate or diverge due to spatial correlations.

2. **DQN vs. Double DQN Value Inflation Test**:
   - Add scalar Gaussian noise ($\mathcal{N}(0, \sigma^2)$) to Q-value outputs in a toy environment.
   - Compare estimated $Q(s, a)$ values under standard DQN vs Double DQN over 500 steps.
   - Verify that standard DQN inflates Q-values past the true maximum return while Double DQN remains bounded.

3. **Behavior Tree Precondition Injection**:
   - Construct a minimal 3-node Behavior Tree (`Selector -> Sequence(Condition: BatteryOK?, Action: RunRLOption) -> Fallback: Recharge`).
   - Trigger a simulated low battery state while the RL option is executing and observe how the BT immediately revokes option execution to enforce safety.
